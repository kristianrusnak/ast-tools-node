# ab - Apache HTTP server benchmarking tool

Load simulation tool for HTTP servers.

ab is a tool for benchmarking your Apache Hypertext Transfer Protocol (HTTP) server. 
It is designed to give an impression of how your current HTTP server performs. 
This especially shows how many requests per second your installation is capable of serving.
