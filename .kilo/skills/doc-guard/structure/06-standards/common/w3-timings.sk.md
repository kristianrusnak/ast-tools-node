# Navigation Timing 	
Základné údaje pre vyhodnotenie latencie pri navigácií z pohľadu koncového browsra. Údaje ako domain lookup, redirect, http connections, unload, load events

[(http://www.w3.org/TR/navigation-timing/)](http://www.w3.org/TR/navigation-timing/)

# Resource Timing 		
Kedže navigation timing pokrýva iba navigáciu medzi stránkami a pre typické AJAX aplikácie je zaujímavé aj monitorovanie dynamicky loadovaných resourcov, táto špecifikácia prokrýva údaje z navigation timing pre tento typ resourcov.

[(http://www.w3.org/TR/2012/CR-resource-timing-20120522/)](http://www.w3.org/TR/2012/CR-resource-timing-20120522/)

# User Timing 			
Umoňuje prídávať vlastné značky do kódu.

[(http://www.w3.org/TR/2012/CR-user-timing-20120726/)](http://www.w3.org/TR/2012/CR-user-timing-20120726/)

# Performance Timeline
Poskytuje jednotné rozhranie pre prístup k User a Resource Timing údajom.

[(http://www.w3.org/TR/2012/CR-performance-timeline-20120726/)](http://www.w3.org/TR/2012/CR-performance-timeline-20120726/)
